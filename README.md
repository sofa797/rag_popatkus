# rag_popatkus
implementation of the term paper


## start 
1. clone repository
   bash```
   git clone https://github.com/sofa797/rag_popatkus.git
   cd rag_popatkus
   ```
2. create .env
   bash```
   cp .env.example .env
   ```
3. run app
   bash```
   docker-compose up -d
   ```
4. open in browser
   bash```
   app: http://localhost:7860
   ```
